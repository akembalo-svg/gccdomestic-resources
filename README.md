## 🌟 What is GCC Domestic?

GCC Domestic is a UAE-founded technology platform that operates entirely on **WhatsApp + Telegram** (no app needed) to:

1. Connect families with **2,100+ government-verified** domestic worker agencies
2. Provide **AI helpers** (Hayat, Nadia, Layla, Amina) in 8 languages
3. Automate **MOHRE eServices** visa paperwork via UAE Pass
4. Host **worker video profiles** + **QR-verified training certificates**
5. Cover all **6 GCC countries** including UAE Tadbeer, Saudi Musaned, Bahrain LMRA

Read more: [About GCC Domestic](https://www.gccdomestic.com/en/about/)

## 🏗 Tech Stack

- **Frontend:** Next.js + nginx + Cloudflare
- **Backend:** Python (FastAPI) + MySQL
- **Messaging:** WhatsApp Business API + Telegram Bot API
- **AI:** OpenAI/Claude APIs + custom Gulf-Arabic fine-tuning
- **Infrastructure:** Single Hetzner box (boring is good)
