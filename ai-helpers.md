# 🤖 GCC Domestic AI Helpers

GCC Domestic operates four AI helpers, all free for families on WhatsApp at **info@gccdomestic.com**.

## 🌟 Hayat (حياة) — Your Family's AI Domestic Helper

The first AI domestic helper that speaks **Gulf-Arabic** the way an actual auntie speaks it (not the textbook fusha Arabic that Alexa/Siri force on the region).

- 🕌 **Prayer-time aware** — knows when Maghrib, Asr, Fajr are
- 🌙 **Ramadan calendar mode** — not a banner, a system mode
- 🍳 **Halal-by-default** — never suggests pork recipes
- 👩‍👧 **Childcare context** — Hayat Umm tracks feeds, sleep, vaccinations
- 🍲 **Iftar planning** — menu + prep order + shopping list
- 💬 **8 languages** — Arabic, English, Tagalog, Hindi, Amharic, Swahili, Indonesian, Urdu

Read more: [Why We Built Hayat — Medium](https://medium.com/@akembalo/why-we-built-hayat-the-first-ai-domestic-helper-that-speaks-gulf-arabic-93581e4ba27c)

## 💼 Nadia — Family-Facing Recruitment Agent

7-language AI agent that helps families:
- Find agencies by country, city, nationality
- Compare salaries and packages
- Track visa/medical/Emirates ID status
- Verify Tadbeer/Musaned/PAM/LMRA/MOL licenses

Read more: [Nadia WhatsApp AI Agent](https://www.gccdomestic.com/en/blog/nadia-whatsapp-ai-agent-domestic-workers/)

## 🏢 Layla — Agency Onboarding Agent

For recruitment agencies registering on the platform:
- License verification workflow
- Worker profile creation (video + QR-verified certificates)
- Lead matching with families
- WhatsApp-native onboarding (no app required)

Read more: [Layla AI Agency Onboarding](https://www.gccdomestic.com/en/blog/layla-ai-agency-onboarding/)

## 🌐 Amina — 24/7 Support Agent

Round-the-clock multilingual support for families, agencies, and workers:
- Real-time agency status checks
- Refund / replacement guidance
- Salary dispute escalation
- Worker rights advisory (per country labour law)

Read more: [Amina 24/7 Arabic AI Support](https://www.gccdomestic.com/en/blog/amina-247-arabic-ai-support-domestic-workers-families/)
